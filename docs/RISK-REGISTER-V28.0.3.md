# Registro de riscos v28.0.3 — Mentor P1–P4

| Risco | Efeito | Mitigação |
| --- | --- | --- |
| Contrato publicado está atrasado ou indisponível | O cartão pode não refletir a origem mais recente | Mostrar o estado da fonte e não substituir ausência por zero; abrir o projeto para a fonte atual. |
| Precisão parece uma medida de conclusão | Interpretação errada do indicador | Identificar como “Precisão publicada”, mostrar o tamanho da amostra e usar uma barra acessível de precisão, nunca de progresso. |
| Tempo local parece compartilhado entre projetos | Leitura incorreta de horas | Rotular como “Tempo · Central · 7D”; manter contratos e registros locais em campos separados. |
| Quatro cartões ficam apertados em telas estreitas | Texto e ações difíceis de ler | Refluxo em duas colunas e, abaixo de 380 px, uma coluna; validar visualmente antes do fechamento. |
| Abas deixam de funcionar com teclado ou hash | Perda de acesso a seções | Tabs ARIA, setas/Home/End, hash change e regressão automatizada. |
| Cache PWA serve CSS ou motor antigo | Usuário vê versão inconsistente | Incrementar versão dos recursos e do cache v28.0.3. |
