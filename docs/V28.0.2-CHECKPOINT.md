# Checkpoint v28.0.2 — próxima ação publicada do PRF

**Estado:** READY_FOR_RELEASE
**Versão alvo:** 28.0.2
**Base:** v28.0.1 no main
**Escopo:** fazer o resumo de foco da Central exibir a próxima ação publicada pelo contrato do PRF, com proveniência e fallback sem unidade inventada.

## Diagnóstico

O contrato read-only do PRF já é gerado a partir do snapshot sanitizado do Notion e publicado pelo workflow próprio. A Central já consulta central-status.json, mas a linha rápida do foco mantinha PRFADM01 fixo e ignorava state.nextAction. Quando o ciclo avançasse, o resumo poderia ficar defasado mesmo com o contrato atualizado.

## Correção

- O foco PRF usa state.nextAction e respeita nextActionKind.
- Contrato em cache antigo aparece como último estado conhecido.
- Sem contrato ou sem próxima ação, a Home orienta a abrir o site do PRF sem afirmar código/unidade.
- TCE-GO, SEEDF e TJDFT permanecem sem alterações; nenhum repositório filho recebe escrita.
- Cache PWA atualizado para v28.0.2.

- Suíte local node tests/quality.mjs: PASS após implementação.
- GitHub Actions e Pages: confirmar após merge.
